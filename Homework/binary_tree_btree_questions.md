## Binary Tree Questions

1. A company stores its employee hierarchy in a binary tree where each manager can have at most two direct subordinates. How can this structure help in representing reporting relationships?

2. A music app stores recently played songs in a binary tree based on song ID. How can the app search for a particular song efficiently?

3. A family genealogy system represents parent-child relationships using a binary tree. How can tree traversal be used to display family members in different orders?

4. In a quiz game, each question has two choices leading to two different next questions. How can a binary tree represent this decision-making process?

5. A courier company tracks package sorting decisions where each node represents a checkpoint and branches represent two possible routes. How can a binary tree help model this system?

## B-Tree Questions

1. A bank stores millions of customer account records on disk. Why is a B-Tree more suitable than a binary tree for searching account details?

2. A library management system stores book records in a B-Tree. How does the B-Tree help in handling large amounts of data efficiently?

3. A database stores student records using a B-Tree index. How does this improve insertion and search speed?

4. A search engine stores indexed web pages in a B-Tree structure. Why is this useful for large-scale disk-based storage?

5. A file system stores directory information using a B-Tree. How does this help in reducing disk access time and improving performance?
