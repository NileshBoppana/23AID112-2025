*5 Questions on Queue*
1. What is a queue? Explain the FIFO principle with a diagram.

2. How is a queue implemented using a linked list? Explain the role of front and rear.

3. Write the algorithm (or code) for the enqueue and dequeue operations in a linked list queue.

4. What happens when you perform dequeue on an empty queue? How is this condition handled in the code?

5. Compare the time complexity of enqueue, dequeue, peek, and search operations in a queue.

*5 Questions on Stack*
1. What is a stack? Explain the LIFO principle with an example.

2. How is a stack implemented using a linked list? What is the role of the top pointer?

3. Write the algorithm (or code) for push and pop operations in a stack using a linked list.

4. What happens when you try to pop an element from an empty stack? How is this handled?

5. Compare the time complexity of push, pop, peek, and search operations in a stack.
